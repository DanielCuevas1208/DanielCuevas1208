# Daniel Cuevas

I build software that makes system behavior visible, testable, and repeatable.

My work covers engineering tools, agent tooling, distributed systems, storage systems, simulation, emulation, and language design.

## Featured projects

### [EngineerMCP](https://github.com/DanielCuevas1208/engineer-mcp)

An MCP server for mechanical-engineering calculations. Each result includes the method, formula, units, assumptions, warnings, and sources.

### [Agent Trace Workbench](https://github.com/DanielCuevas1208/agent-trace-workbench)

A local Python workbench for recording, replaying, comparing, and inspecting tool-using agent runs. It stores trace data on the local system.

### [EngineerProfile](https://github.com/DanielCuevas1208/engineer-profile)

A TypeScript tool that builds a static portfolio from public repository evidence. It creates project pages, changelogs, and publishing drafts.

### [Signal Garden](https://github.com/DanielCuevas1208/signal-garden)

An Elixir simulator for distributed systems. It runs deterministic scenarios with delay, partitions, retries, and headless replay.

### [Cinderstore](https://github.com/DanielCuevas1208/cinderstore)

An embedded Crystal key-value store. It uses a write-ahead log, sorted data files, snapshots, and level-based compaction.

### [Sprout Language](https://github.com/DanielCuevas1208/sprout-lang)

A small Go programming language with an interpreter and a bytecode virtual machine. It supports file modules, imports, exports, and cycle checks.

### [Gatework](https://github.com/DanielCuevas1208/gatework)

A Haskell digital-logic simulator. It reads text netlists and writes standard VCD waveform files.

### [Dungeonwright](https://github.com/DanielCuevas1208/dungeonwright)

A Godot dungeon crawler with seeded maps and multi-floor runs. Dungeon depth controls enemy scaling.

### [Local-first Job Queue](https://github.com/DanielCuevas1208/local-first-job-queue)

A Go and SQLite background job queue. It includes leases, retries, idempotency, a dead-letter queue, metrics, and a read-only dashboard.
